# Orbit status

Updated 2026-11-25. Architecture: [design](design.md). Docs map: [docs/README](README.md). Task records: [index](tasks/README.md).

**Stage.** R0–R2 validated on this machine. R3 benchmarks run: LongDS with one complete native Codex task, Harbor with oracle/empty samples. R4 (multi-node) only as two daemons on one machine. No release blockers.

## Available

- **Package and plugins.** npm [`@zjunlp/orbit`](https://www.npmjs.com/package/@zjunlp/orbit) ships Web, skills and licenses; one-command plugins for Claude Code, Codex, dsh and pi ([plugin guide](../plugin/README.md), [releasing](guides/releasing.md)).
- **Daemon and CLI.** Auto-started local daemon (127.0.0.1, token/cookie, single writer per home); `orbit run / sweep / ps / show / logs / wait / cancel / note / resources / doctor / web / auth / notify / bench / node / data`; `pnpm verify` gates changes.
- **Resources.** Leases with queue reasons; outside use respected (busy GPUs, CPU, `MemAvailable`); `orbit reconcile` every 10 min; at most `ORBIT_MAX_STARTING` (4) starts and none under 5 GB free disk; GPU holders and device leases in CLI/Web; KVM/DRI/TUN/adb/serial probes.
- **Execution.** Docker with code snapshot, CDI GPU mapping checked against the lease, execution-only timeouts, durable ending phases, evidence collected before cleanup; opt-in failure [checkpoints](guides/checkpoints.md) and `orbit resume`; `--check` / `--smoke` preflight; separate data directory and logical folders.
- **Trajectories.** ATIF v1.5–v1.8 contract; Codex / Claude Code conversion, native Harbor/Cua ATIF adoption and automatic Run storage, lazy legacy backfill, versioned rebuild, API/CLI and worker forwarding. Virtual step review with sub-Agents, tools and linked environments reads ATIF; token accounting derives from ATIF; CLI, reports and comparison views show usage with missing-data coverage; GUI, episode and conversation reviews link to ATIF steps ([guide](guides/trajectories.md)); filtered ATIF/Chat JSONL exports include media, integrity manifests and secret checks ([export](guides/trajectory-export.md)).
- **Agents.** Registry of 12 Agents plus user definitions (`orbit agent …`), installed inside the run when needed. Real runs: codex, claude-code, dsh; the other nine are unverified. Auth profiles per Agent; notifications (Feishu, DingTalk, WeCom, Slack, webhook; Feishu app bot).
- **Bench core.** Solve + independent verify per trial; valid-only means with task-clustered CI and paired Δ; benchmark's official aggregation shown alongside; closed failure kinds; immutable report revisions; reproducible evolve/gate/final splits and frozen task-file submissions ([guide](guides/task-sets.md)); `rescore`, `consolidate`, `usage`, `calibrate`, `coverage`; evolution gate CLI/API, read-only evaluation plans, bundle preflight, frozen evidence records and bounded real Codex calibration ([guide](guides/bench-gate.md)).
- **Integration.** One adapter protocol behind four integration methods: `harbor`, `manifest`, `sdk`, `native` (design §9.14). Harbor covers compose services, hooks, per-role GPUs and verifier GPU models; TB-Science 70/70 and TB 4.0 56/66 supported.
- **Benchmark resources.** CLI/Web preparation lists all 63 families, with official-source downloads, reuse, authorization guidance and validated registration ([guide](guides/benchmark-resources.md)); the ten additional legal, healthcare, finance, memory, utility, proof and audio families currently require guided setup and definition import. **Describing benchmarks.** Six-dimensional taxonomy, integration method, calibration record (design §9.10). Product library of 63 families with source-backed route/profile tags and explicit unknowns ([catalog](catalog.md), [availability](guides/benchmark-availability.md)).
- **New native adapters.** CLI solves have model network access and SWE-bench shares its catalog identity ([review fixes](tasks/20261117-native-adapter-review-fixes.md)). HealthBench, LongMemEval, FinanceBench, AgentDojo clean utility, SWE-bench, AppWorld and miniF2F preserve private grading inputs and original scoring; bounded real Docker checks passed. Alternative LLM judges and published human-label replay have explicit limits ([scope](tasks/20261116-remaining-benchmarks.md)). AgentDojo and AppWorld sampled live services, native replay and cleanup passed using private Unix sockets ([fix](tasks/20261117-tool-service-sockets.md)).
- **Calibrated samples.** Bounded empty/oracle or scripted calibration for HumanEval, EFE MetaWorld+, BFCL, τ²-bench, MiniWoB, LIBERO, TextArena, Cua Bench basic desktop, CUA-Lite MiniWoB; LegalBench, LawBench and MMAU each have four real Docker task checks and native grading comparisons ([scope](tasks/20261116-benchmark-expansion.md)); BFCL also has a real CLI Agent check; public HLE with tools has text/image CLI samples, original-prompt alternate-judge controls and rescore checks.
- **GUI.** Private signed GUI service (`orbit-computer` CLI/MCP); Claude Code and Codex verified on sampled MiniWoB/BrowserGym tasks; MCP servers wired into Claude/Codex homes ([GUI guide](guides/gui-bench-web.md)).
- **Embodied.** GalaxeaVLA G0.5 for native RoboTwin; base LIBERO uses official source and RoboTwin uses pinned `ea8b211` with regenerated sample plans. Native policy evaluation with semantic bindings, frozen samples, CPU evidence verification and rescore; shared model services in batches ([quickstart](guides/embodied-quickstart.md), [compatibility](guides/embodied-compatibility.md)). BEHAVIOR-1K uses its native R1Pro evaluator; RobotAgentBench adds raw-22 Agent tools alongside RLE-Bench, EmbodiedCLBench and EmbodiedLab T0 (BEHAVIOR / RobotAgentBench native preparation and calibration deferred).
- **Web.** Responsive run tables, restored scroll positions, accessible controls, quoted CSV previews and corrected failure navigation ([integration](tasks/20261125-remote-branch-integration.md)). Overview · Benchmarks · Agents · Configurations · Evaluations · Runs · Resources; trial views follow evidence shapes, including RoboDojo/RoboLab timelines and recorded TextArena conversations; virtualized long conversations with searchable tool results, URL/keyboard navigation and cancellable Trial reads; configuration lineage with immutable gate verdicts, missing-evidence details and frozen parent/child trajectory comparisons; read-only [transfer matrices](guides/transfer-matrix.md) across benchmarks, Agents and frozen conditions.
- **Multi-node.** Workers join by token; placement, hashed code bundles, named datasets, mirrored logs and artifacts ([guide](guides/multi-node.md)).

## Main gaps

- **Validation.** Native embodied checks include sampled simulator runs, real-policy rollouts and short upstream comparisons. Full-suite statistical equivalence with upstream evaluators remains unverified. [Coverage and evidence](guides/embodied-compatibility.md).
- **Not run for real.** MobileWorld / OSWorld-V2 KVM calibration; EFE GPU tasks; EmbodiedLab experiments (RTX startup); BEHAVIOR-1K / RobotAgentBench native calibration; WebVoyager and Web judge calibration; R4 on two machines; LongDS Claude continuation.
- **Missing.** Environment pools and `slots`; episode importers beyond EFE, RoboTwin, LIBERO, RoboDojo and RoboLab; Harbor licensed-data volumes (ManiGuard); allowlist networks, multi-step Harbor tasks, Harbor MCP tool sets; MCP server; native Policy view in Agents; bundle cache eviction.
- **Known issues.** Docker [`userns-remap`](guides/docker-userns-remap.md) breaks Run output writes and is not detected; daemons of different users on one machine can lease the same free GPU.
