# DM0.5 on native VLA-Arena

branch: feat/embodied-eval · status: completed · updated: 2026-11-12

## Goal

Evaluate the released DM0.5 Arena checkpoint through the native benchmark and independent CPU verification.

## Changes

- Pin the OpenDM source and register its local checkpoint, processor and normalization as an independent Policy.
- Declare the Policy's observation and action semantics independently and validate the benchmark mapping before registration.
- Register the OpenDM recipe across all 11 native Arena suites, with the first published state per task, ten controls per model query, and the official episode seed derivation.
- Preserve unrotated images, the eight-element Panda state, the translation and gripper thresholds, and ungated native task success with unscaled constraint cost. The OFT recipe retains its existing behavior.
