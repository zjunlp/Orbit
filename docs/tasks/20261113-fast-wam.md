# Fast-WAM on native LIBERO Spatial

branch: feat/embodied-eval · status: completed · updated: 2026-11-13

## Goal

Run the released optional-IDM checkpoint on LIBERO Spatial in both inference modes.

## Changes

- Register two independent policy endpoints for `first_frame` and `idm` with a shared checkpoint and normalization identity.
- Run the same ten Spatial tasks and fixed initial states with MuJoCo 3.3.2, 30 settle steps, a 400-control horizon and ten controls per query.
- Use the two native camera views and the release's state normalization, denoising settings and native gripper conversion.
