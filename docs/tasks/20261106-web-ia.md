# Web 信息架构与方法迭代
branch: feat/web-ia-finish · status: completed · updated: 2026-11-06

## Goal

实现 [design §9.16](../design.md)：让 benchmark 类型与领域、Agent 支持情况、方法版本及迭代证据在 Web 上可发现、可筛选、可复盘。

## Changes

- 有文字的可折叠侧栏；Overview、Benchmarks、Agents、Methods 一级页面，保留评测与运行入口及旧 Catalog 链接。
- Benchmark 身份归并、受控领域与细分标签、编辑标签、分类/领域/证据分面和覆盖矩阵；修正适配器的身份版本及可配置 benchmark 归并。
- Agent 能力按声明/接线/证据区分；凭据和当前兼容性独立显示，历史实跑不覆盖当前阻断原因。
- 方法 revision、显式派生来源、条件约束的配对比较；旧记录保留 approximate，跨 revision 重试不能归并。
- 修补首页错误恢复、侧栏提示、单次任务列表刷新、从多方法或旧作业只派生当前方法；拒绝未改变内容的 self-parent。
- Methods 按条件和任务集分开显示，支持主/次指标、固定报告与退步任务入口；完成窄屏和明暗主题布局。
