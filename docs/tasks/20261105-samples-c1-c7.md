# C1 / C7 样板：HumanEval（固定输入）与 TextArena（游戏）
branch: feat/samples-c1-c7 · status: completed · updated: 2026-11-05 · owner: Claude

## Goal

按 [integration-categories](../integration-categories.md) 给 C1 与 C7 各做一个直接接入的样板，并对 C3 / C4 的样板做
主线验收。C2（EFE）、C5（MiniWoB）、C6（LIBERO）已有样板。

## Changes

- **C1 HumanEval**（`examples/bench-adapters/humaneval/`，直接注册 `openai/human-eval@312c5e5` 的数据）：
  数据 sha256 固定；被测方只看到 prompt（签名与 docstring），测试与参考解不进 solve；verify 在无网络容器里运行原版检查
  程序（`prompt + completion + test + check(...)`，每题 3 秒，与 `evaluate_functional_correctness` 相同）；oracle 用原版
  canonical solution，empty 为空补全；`external`（OpenAI 兼容端点，config `model`/`baseUrl`，key 经 passEnv）已实现但未运行。
- **C7 TextArena**：用 Harbor 转换器从上游 `textarena@0.7.3` 生成 38 个有 oracle 的单人游戏到
  `orbit-samples/data/textarena/tasks`（仓库外），登记为内置 `harbor` 适配器、`-c category=game -c profiles=single-player,turn-based`。
- **Harbor 适配器**：`category` / `profiles` 登记选项——Harbor 只是格式，数据集的类别由登记声明（默认 agent-workspace）；
  Harbor 任务都带 `solution/`，声明 `calibration.oracle = "max"`。
- **非 root 镜像用户**（TextArena 主镜像 `USER agent`）：阶段脚本目录 `/orbit/phases` 设为 0777，权威回执仍只在
  daemon 的 `phaseStateDir`；shared 模式暂存的 `tests/test.sh` 在宿主上 chmod 0755，容器内 `chmod +x` 失败不再中断 verifier。
- **游戏未完成是方法的 0**：TextArena 游戏服务对未结束的对局返回 425（game not finished yet），这是方法自己的 0；
  只有服务不可达或其他状态码判 invalid（`infra`）。
- **CLI**：`bench show` 显示类别与 profile，不再显示旧 `kind`。
- **审查修正**：BFCL 样板的宿主单测在缺少 `bfcl-eval` 时 skip（而不是 error），与 τ² 样板一致。
