# Native VLA-Arena

branch: feat/embodied-eval · status: completed · updated: 2026-11-11

## Goal

Run the 11 official VLA-Arena suites with independently registered policies and CPU evidence verification.

## Changes

- Pin the Arena environment, 170 L0–L2 tasks, BDDL files and 8,500 indexed initial states.
- Apply the native settling, horizon and safety-cost rules. Preserve costs and effective instructions for rescore.
- Generate separate V0–V4 and W0–W4 registrations with frozen visual options and indexed language replacements.
- Report per-level success and safety cost in the method summary using the frozen task difficulty.
