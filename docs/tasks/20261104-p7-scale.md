## Changes

- `runs/reconcile.ts` + `docker.labelledResources`：每 10 分钟（`RunService.reconcile`，`POST /api/reconcile`，
  `orbit reconcile`）列出带本 home 标签的容器/网络/卷；Run 已结束且清理确认、或记录已删除 → 删除（容器先于网络与卷）；
  无 Run 标签、Run 仍在观察中 → 不动；任何列表失败 → 整轮跳过。活动租约的 Run 已结束且清理确认或已删除 → 释放并记事件。
  契约 `ReconcileReport`。
- `resources/allocate.hostProtection`：数据盘剩余 < 5 GB 时不在本机启动新 Run；处于 starting 的 Run 达到
  `ORBIT_MAX_STARTING`（默认 4，`RunService` 选项 `maxStarting`）时其余排队并写明原因；远端放置不受本机限流影响。
- 多节点：设备与 GPU 型号限制逐角色参与 `remoteBlocker`（P6.5 起 `infeasible` 带角色），补测试。
- `docs/catalog.md`：各 benchmark 的接入层级、方法、可运行任务数、真实校准情况与证据链接；EFE 不可运行的套件与原因。
- design §9.6（P7 实现与后置理由）、§9.13 P7 行，status 同步。
