# CLIPort native language-conditioned evaluation

branch: feat/embodied-eval · status: completed · updated: 2026-11-13

## Goal

Run the official CLIPort language-conditioned test split through Orbit with native scoring.

## Changes

- Register all 18 test entries. Freeze up to 100 oracle-qualified seeds per entry with each seed’s post-reset primitive limit.
- Forward three RGB-D camera views and the current subgoal. Run the native primitives in PyBullet 3.0.4 DIRECT on CPU. Register suction pick/place and spatula push with separate action profiles. Use cumulative reward as the primary score and report completion above 0.99 separately.
- Restore the shared color palettes after each reset. Some upstream tasks shuffle these lists in place, so restoring them keeps scenes and language reproducible across episode ordering.
- Isolate temporary URDFs across oracle workers.
- Register the released CLIPort checkpoint as a separate Policy with an offline RN50 backbone and the upstream loader’s module modes.
