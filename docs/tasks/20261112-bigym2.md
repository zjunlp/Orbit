# BiGym 2.0 native learned-policy evaluation

branch: feat/embodied-eval · status: completed · updated: 2026-11-13

## Goal

Run the official BiGym 2.0 learned-policy task suite through Orbit's native adapter.

## Changes

- Register all 20 tasks and their 100 evaluation seeds per task. The two G1 profiles cover six 20D tasks and fourteen 21D tasks.
- Preserve the native 50 Hz control, cameras, per-task horizon, frozen GR00T-WBC controller and success rule that excludes falls.
- Verify stopping and success using saved control evidence independently of the Policy service.
