# Native MolmoBot v2 evaluation

branch: feat/embodied-eval · status: completed · updated: 2026-11-13

## Goal

Register the seven MolmoBot v2 conditions with pinned offline assets and native rendering.

## Changes

- MolmoSpaces adds the seven published MolmoBot v2 conditions with five distinct
  1,000-episode catalogs, separately from MS v1. The two renderer versions and
  randomized exocentric camera are recorded in the reference.
  [MolmoBot protocol](https://github.com/allenai/molmospaces/blob/v0.2.9/molmo_spaces/evaluation/mb-bench.md)
- The RandCam DROID Policy declares the exocentric view explicitly and reuses the
  existing DROID checkpoint dataset.
