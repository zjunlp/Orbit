# Motus on RoboTwin 2.0

branch: feat/embodied-eval · status: completed · updated: 2026-11-16

## Goal

Run the released Motus video-action checkpoint with native RoboTwin joint control.

## Changes

- Register the Clean and Randomized suites with native three-view input and 16-control chunks. Preserve the native lighting stream between policy queries.
- The [pinned policy image](../../examples/bench-adapters/embodied/policies/motus/README.md) loads the T5 weights on CPU before moving the BF16 encoder to CUDA. This avoids placing the temporary FP32 encoder on the GPU.
